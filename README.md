# Dig-Pick ![Логотип](Materials/PNG%20Textures/logo.png)


**2D-песочница в браузере с открытым исходным кодом.**  
Копай, строй, исследуй и развивайся в бесконечном мире — по мотивам Terraria и Minecraft.

## Как запустить?

**Способ 1: Онлайн** — перейди по [ссылке](https://bbqquuiieedd.github.io/Dig-Pick/) и играй без скачиваний. Всегда самая свежая версия: обновлять ничего не нужно.  
**Способ 2: Локально** — скачай проект и открой `index.html` в браузере. Работает без интернета. Чтобы обновиться до новой версии — просто скачай более свежую сборку.

> **ВАЖНО.** Сохранения из разных способов **не пересекаются** — у онлайн-версии и у локальной копии свои данные. Учитывай это при выборе способа игры.  
> При обновлении проекта старые сохранения **могут перестать поддерживаться** — формат меняется вместе с игрой. Скачанная локально копия сама не обновится, но и сохранения в ней останутся нетронутыми.
