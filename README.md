# Dig-Pick

## Список дел
- Консоль с простой реализацией команд (с простым пополнением человеком)
- Переделать перетягивание вещей из инвентаря
- Поработать над закрытием инвентаря на Esc

## Список идей
- Главное меню
- Логотип (кирка, сделать анимацию из старого дигпика (фон тоже))
- Простая анимация ходьбы (кадрами из PNG файлов)
- Достижения
- Импорт и экспорт данных сохранений
- Добавить текстуры под разные праздники (разные сезоны)
- Система сидов (с случайной генерацией или по ключу)
- Реализовать управление на мобильных устройствах
- Смена времени
- Настройка персонажа и мира
- Обучение
- Разбить файлы .js
- Сделать разное время для ломания блоков
- Трава должна понемногу распространяться, (если рядом блок травы, поверх земли вырастет трава спустя время)
